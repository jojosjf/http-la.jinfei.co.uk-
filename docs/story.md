# 问剑录 · 剧情设定

> 题材取当下修仙网文里受众最广的组合：**天才陨落 → 废柴逆袭 + 灭门之仇 + 随身老爷爷（剑中残魂）+ 宗门大比宿敌 + 冷面仙子**。
> 全部人名、宗门、招式均为原创。对白写在关卡 JSON 的 `events` 里（见 `src/data/scenarios/`），本文件是总纲。

## 一句话

三年前一夜被灭门、被人剜去剑骨的问剑宗天才云衡，带着断剑里祖师的一缕残魂从炼气重修，一路向天工宗讨回剑骨与公道。

## 世界

- **九州末法**：灵脉一年比一年稀薄，修士突破越来越难。
- **天工宗的主张——以器代人**：用机关傀儡占灵脉、替修士征战。天工宗因此十年间从三流宗门做成九州第一大宗。
- **天工宗的秘密**：上等傀儡的核心「灵枢」，要用活修士的灵根、剑骨炼成。傀儡越强，背后死的修士越多。

## 势力

| 势力 | 说明 |
|---|---|
| 问剑宗（已灭） | 剑修宗门，山门在问剑峰。镇派之剑「无归」。三年前一夜覆灭。 |
| 天工宗 | 机关傀儡宗门。宗主公输衍（幕后），长老厉寒舟，外门执事偃无常。 |
| 玄霜阁 | 北境女修宗门，擅冰法与雷法、医道。 |
| 太素剑阁 | 名门正派，自称天下剑道第一。 |
| 散修 | 无门无派的修士，石破军即是。 |

## 我方

- **云衡**（18，游方剑修）
  - 问剑宗末代弟子，生来「先天剑骨」，十五岁筑基，被称作百年一遇。
  - 灭门那夜，剑骨被厉寒舟亲手剜去，修为跌回炼气。
  - 性子：看着随和爱笑，骨子里极执拗。
  - 随身带着断剑「无归」。
- **剑灵 · 晏长歌**（无归剑中的问剑宗开山祖师残魂）
  - 嘴毒，嗜酒，只能闻酒香。平时爱挖苦云衡，关键时刻最靠得住——就是那位「随身老爷爷」。
  - 对白里写作「剑灵」，只有云衡听得见。
- **苏清寒**（19，玄霜阁真传）
  - 冷面寡言，冰法、雷法、医术都精。
  - 师尊霜华真人在天工宗地界失踪。
  - 她会玄霜阁秘术「冰魄续脉」，能重续断脉。于是和云衡做了笔交易：他护她进天工宗地界，她替他续脉。
- **石破军**（26，散修）
  - 前镖师，嗓门大、饭量大、最讲义气。
  - 三年前在问剑峰下被云衡的师父救过命，从此认云衡做「少主」——云衡很嫌弃这个称呼。
- **林玄**（19，太素剑阁首席）
  - 天之骄子。十二岁那年宗门大比，输给过云衡一剑，至今耿耿于怀。
  - 奉命调查坊市修士失踪案。起初瞧不上跌了境界的云衡；被救之后改口，成了亦敌亦友的同伴。

## 敌方

- **偃无常**（天工宗外门执事）
  - 笑面虎，倒卖「灵骨」，什么都能拿来标价。
  - 坐驾：镇宗傀儡「六臂明王」。
- **厉寒舟**（天工宗长老）
  - 三年前血洗问剑峰的主事者，冷酷寡言。
  - 把云衡的剑骨炼成了移动要塞「镇岳天城」的灵枢。
- **公输衍**（天工宗宗主）：幕后之人，第 3 话结尾才露面。
- **天工宗傀儡**：焚炉、锁魂、血螳、黑垒、鬼灯等。傀儡核心里锁着修士残魂，所以击破时会有「解脱」的叹息。
- **神兽**（白泽、潜鳞、烛龙）：被天工宗用锁魂钉强行驱使，留作后续章节。

## 第一卷 · 剑骨（第 1～3 话）

### 第 1 话 河畔遇伏

- **地图**：河岸，山门废墟在左下。
- **胜利条件**：全灭敌人。**失败条件**：云衡被击败。
- **剧情**：
  - 云衡、石破军护送苏清寒南下，渡青川河时遭天工宗傀儡伏击。剑灵第一次开口。
  - 苏清寒发现傀儡核心里有修士的气息，埋下伏笔。
  - 击破领头的血螳：核心里滚出一截修士指骨。云衡认出指骨上问剑宗的剑纹。
  - 三人决定去百珍坊市，查灵骨的来路。

### 第 2 话 坊市暗潮

- **地图**：百珍坊市，城中有一条运河。
- **Boss**：偃无常（六臂明王）。
- **胜利条件**：击败偃无常。**失败条件**：云衡被击败。
- **剧情**：
  - 夜市里，偃无常正在拍卖「问剑宗剑修灵骨」。林玄一人闯进来，被傀儡围在东市。
  - **第 1 回合**：林玄嘴硬，说不用帮忙。
  - **第 2 回合**：偃无常认出云衡，「当年那个剜了剑骨的废物」。
  - **第 3 回合**：明王起身；北面灰鸢增援。
  - **偃无常气血过半**：施展狂怒 + 坚守，「明王，开第三臂！」。
  - **击破六臂明王**：偃无常捏遁符逃走，留下一本账册——「剑骨×1，送镇岳天城，厉长老亲收」。
  - **结尾**：林玄承认云衡，同行去问剑峰。

### 第 3 话 问剑峰

- **地图**：问剑宗旧山门，山道蜿蜒而上，一条瀑布溪穿山而下。
- **Boss**：厉寒舟（镇岳天城）。
- **胜利条件**：击败厉寒舟。**失败条件**：云衡被击败。
- **剧情**：
  - 天工宗在问剑峰挖祖师剑冢，镇岳天城坐镇山门。云衡三年后第一次回山。
  - **第 3 回合**：两翼增援（灰鸢、赤轮）。
  - **云衡与厉寒舟交手**：战前对话，仇人相见。
  - **镇岳天城气血过半**：剑骨与云衡共鸣。剑灵大笑「这一剑，我等了三年」，云衡战意 +30。
  - **击破镇岳天城**：天城崩塌，剑骨化作一道白虹回到云衡体内。厉寒舟死前说出「宗主要的不是剑骨，是整个九州的灵根」。
  - **结尾**：远处，公输衍的声音响起。第一卷完，待续。

## 之后（第二卷构想）

- 玄霜阁之变：苏清寒的师尊也被炼成了灵枢。
- 太素剑阁内鬼：林玄的师门里有人与天工宗交易。
- 神兽篇：解救被锁魂钉驱使的白泽、潜鳞，烛龙是天工宗的终极兵器。

## 写对白的约定

- **说话人**：用角色 id（`yunheng` / `suqinghan` / `shipojun` / `linxuan` / `yanwuchang` / `lihanzhou`），会显示名字和头像。其他说话人直接写名字，如「剑灵」「天工宗弟子」；写「旁白」则不显示名字框。
- **长度**：每句不超过 60 个字（对话框宽 380 像素、三行）。
- **语气**：云衡带点痞气，苏清寒字少，石破军嗓门大、爱用感叹号，林玄傲，剑灵毒舌。
